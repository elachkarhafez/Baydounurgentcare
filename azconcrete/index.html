How a replacement goes

This is that same approach, start to finish. Every job runs the same way.

01

Break out the old slab

We cut clean edges and pull the broken concrete out with the loader, so the new pour ties in straight.

02

Gravel base and forms

Gravel goes down and gets packed, then the forms get set so water runs away from the house.

03

Pour and screed

The truck pours, and we screed it flat and level before it starts to set.

04

Edge and finish

Clean edges, control joints and a broom finish for grip. Stamped and colored if you want it.

05

Tape it off and clean up

Caution tape goes up while it cures, and we leave the place cleaner than we found it.
